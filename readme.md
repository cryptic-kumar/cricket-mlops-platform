# Cricket MLOps Platform

Production-oriented MLOps platform for cricket analytics.

## Overview

This project implements an end-to-end MLOps lifecycle:

Data
↓
Training
↓
Experiment Tracking
↓
Model Registry
↓
Fairness Gate
↓
Production Serving
↓
Monitoring
↓
Drift Detection
↓
Retraining

## Features

- Versioned cricket dataset
- MLflow experiment tracking
- Model registry
- Accuracy-based promotion
- Fairness gate
- Production model serving
- SHAP explanations
- API rate limiting
- Input validation
- Prediction audit logging
- Data drift detection
- Automatic retraining trigger
- CI/CD
- Terraform infrastructure
